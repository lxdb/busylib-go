## Documentation boundaries

The guides explain repository-wide contracts and common workflows. Package comments and runnable examples remain the source of truth for Go APIs. Tests define executable behavior. Workflows and release configuration define automation behavior.

The dated files under `research/` preserve evidence used for a specific decision. They are historical records, not current operational guidance.
