# Support

Use [GitHub Issues](https://github.com/lxdb/busylib-go/issues) for reproducible defects, documentation errors, and focused feature requests.

Include the module version or commit, Go version, firmware version, transport, exact error, and the smallest reproduction that does not expose sensitive data. Remove access keys, broker credentials, device tokens, and personal data.

This project does not provide emergency or guaranteed support. Follow [SECURITY.md](SECURITY.md) for confidential vulnerability reports; do not post undisclosed vulnerability details in an issue.
