# Code of conduct

## Expected behavior

Treat other participants with respect.
Give technical feedback about the work, not the person.
Assume good intent while you ask for evidence.
Respect privacy and remove sensitive information.

## Unacceptable behavior

Harassment, discrimination, threats, and sustained disruption are not acceptable.
Do not publish another person's private information.
Do not use sexualized language or unwanted attention.

## Enforcement

Report conduct concerns privately through the repository owner profile.
Do not include secrets in a report.

Maintainers can edit, reject, or remove contributions that violate this policy.
Maintainers can temporarily or permanently restrict participation.
